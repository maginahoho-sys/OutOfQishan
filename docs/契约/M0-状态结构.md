# M0 · GameState 状态结构总纲（所有模块的共同契约）

> 本文件是所有模块的最高契约。任何模块读写状态都必须遵守本文件的结构定义。

## 铁律

1. `state` 里只放**纯数据**（对象/数组/字符串/数字/布尔/null），禁止放 Phaser 对象、函数、类实例。
2. 逻辑层（`src/logic/`）**禁止 import phaser**，只操作 state + 通过 EventBus 发事件。
3. 渲染层（`src/scenes/`）只读 state 画图、把用户输入转成对逻辑层函数的调用。
4. 修改 state 后必须发事件（事件名见 `src/core/EventBus.js` 头部注释）。

## 状态结构

```js
state = {
  version: 1,                       // 存档版本号
  meta: {
    day: 1,                         // 当周第几天（1~7）
    week: 1,                        // 第几周（每周一刷新兵种产量）
    currentPlayer: 0                // 当前行动玩家下标（0=人类蜀汉, 1=电脑曹魏）
  },
  players: [{
    id: 0, faction: 'shu', isAI: false,
    gold: 10000, wood: 20, ore: 20, mercury: 5, sulfur: 5, crystal: 5, gem: 5
  }],
  heroes: [{
    id: 'hero_shu_0',
    playerId: 0,
    name: '刘备',
    level: 1, exp: 0,            // exp = 距下一级还差的经验（M6c）
    pendingLevels: 0,            // 待加技能点次数（M8：chooseSkill 每选一次减 1）
    movePoints: 20, maxMovePoints: 20,   // 每日行动力（含行军技能加成）
    mana: 10, maxMana: 10,               // 法力（M9：战斗内施法消耗，每日恢复 +5 不超上限）
    pos: { x: 3, y: 13 },                // 地图格子坐标
    skills: { leadership: 1 },           // 技能id: 等级（M8，数值见 src/data/skills.json）
    spells: ['heal', 'bless'],           // 已习得魔法id（M9：升级时按等级自动补齐本阵营魔法）
    army: [{ unitId: 'shu_militia', count: 40 }]  // 最多7格
  }],
  towns: [{
    id: 'town_shu_0',
    playerId: 0,
    faction: 'shu',
    name: '成都',
    pos: { x: 2, y: 14 },
    buildings: ['hall'],                 // 已建建筑id
    recruitPool: [{ unitId, count }],    // 本周可招募产量（M4 每周一刷新）
    builtToday: 0,                       // 当日已建造次数（M5 用）
    garrison: [{ unitId, count }]        // 驻军
  }],
  map: {                                 // 来自 src/data/map_default.json
    name: '祁山之战',
    width: 30, height: 18,
    tiles: [[0,1,2,...], ...],           // 地形码，见下
    objects: [{ type: 'resource', resource: 'gold', amount: 600, pos: {x,y} }],
    starts: [{ faction, heroPos, townPos }]
  },
  battle: null,                          // 战斗中为战场状态对象（见 M6 契约）
  gameOver: null                         // { winnerId, reason }
}
```

## 地形码

| 码 | 地形 | 可走 | 行动力消耗 |
|---|---|---|---|
| 0 | 平原 | ✅ | 1 |
| 1 | 森林 | ✅ | 2 |
| 2 | 山地 | ❌ | — |
| 3 | 水域 | ❌ | — |
| 4 | 道路 | ✅ | 0.5（两格算1点，见 M2） |

## 资源字段

`gold` 金、`wood` 木、`ore` 矿、`mercury` 汞、`sulfur` 硫、`crystal` 晶、`gem` 宝。
所有花费/产出统一用这 7 个字段的对象表示，如 `{ gold: 500, wood: 5 }`。
