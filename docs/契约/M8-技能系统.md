## 目标

实现英雄升级与技能加点。规则简化自英雄无敌4：英雄升级时从技能池随机 3 个选项（已学技能升级 or 新技能），玩家选 1。

## 技能表来源（重要口径）

本模块用 **静态 import** 引入 `src/data/skills.json`：

```js
import SKILL_TABLE from '../data/skills.json' with { type: 'json' };
```

**原因**：契约冻结了 `skillBonus(state, heroId, effectType)` 的签名（**不带 `data` 参数**），
而技能加成必须知道 `perLevel`。若 skillBonus 去读运行时 `data`、其他函数读静态表，
两边一旦不一致就会出现"加成算得出、选项列不出"的错位。

因此：**技能定义以静态表为唯一权威源**，`data` 参数只为契约签名保留。
（DataLoader 仍会加载 skills.json 供 M7/M13 展示用，两份内容同源。）

> 技术前提：JSON import attributes 需要 Node ≥ 20.10 / Vite ≥ 5。
> 本项目已在 Node 22.22 + Vite 5.4 的 dev 与 build 双端实测通过。

## 规则细节（M8 定案）

1. **候选池** = 已学但未满级的技能（继续升）+ 尚未学过的技能（学新）。
   满级技能**不再出现**在候选里；全部满级时 `levelUpOptions` 返回空数组。
2. **候选数量** = 3，不足 3 个则有几个给几个（Fisher-Yates 洗牌后取前 N）。
3. **一次加点消耗一次 `pendingLevels`**。连升多级时，每点独立消耗一次。
4. **即时效果**（`chooseSkill` 内立即生效）：
   - 行军（`movePoints`）→ 抬高 `maxMovePoints`，并按差额**补足当前 `movePoints`**
   - 谋略（`mana`）→ 抬高 `maxMana`，并按差额**补足当前 `mana`**
   - 上限只增不减；补足后不超过新上限。
5. **电脑方英雄自动加点**：`resolveBattle` 给 AI 英雄发经验后，
   按效果类型权重自动选点（统帅10 > 防御9 > 武勇8 > 弓术7 > 行军5 > 谋略4 > 理财3 > 医疗2），
   同权重时优先把当前等级低的先练起来。**玩家方英雄留给界面处理**。
6. **`skillBonus` 口径**：所有模块查询技能加成的**唯一入口**，签名不可改。

## 技能效果类型与生效位置

| effect.type | 技能 | perLevel | 生效位置 |
|---|---|---|---|
| `armyAttack` | 统帅 | 1 | M6 `initBattle` 烘进 `stack.attack` |
| `armyDefense` | 防御 | 1 | M6 `initBattle` 烘进 `stack.defense` |
| `rangedDamage` | 弓术 | 10（%） | M6 `computeDamage` 乘 `1 + pct/100` |
| `meleeDamage` | 武勇 | 10（%） | M6 `computeDamage` 乘 `1 + pct/100` |
| `movePoints` | 行军 | 4 | M4 `refreshMovePoints` + `chooseSkill` 即时效果 |
| `mana` | 谋略 | 10 | M4 `refreshMovePoints` + `chooseSkill` 即时效果 |
| `goldPerDay` | 理财 | 200 | M4 `dailyIncome` |
| `healBonus` | 医疗 | 20（%） | M9 魔法系统（待交付） |

**伤害加成的适用范围**：`rangedDamage` 只作用于带 `ranged` 特性的 stack，
`meleeDamage` 只作用于近战 stack。`initBattle` 时按 stack 的特性二选一写入 `stack.damagePct`。

## 界面（M8 附带交付）

`src/scenes/ui/skillPanel.js` 提供可复用弹层：

```js
openSkillPanel(scene, { state, data, heroId, onDone })
// 遮罩 + 3 张技能卡；点卡即 chooseSkill
// 还有剩余次数 → 就地刷新新候选；点完 → 关闭并回调 onDone
```

接入点：
- **MapScene** 状态栏显示 `[英雄名 技能加点 N]`，点击打开面板
- **TownScene** 底栏显示英雄 `Lv.` / 经验进度 / 已学技能一览，有剩余点数时显示加点按钮
- **BattleScene** 结算面板显示 `[技能加点 · 还剩 N 次]`；
  点「确定」时若仍有剩余点数会先引导加点，避免漏点

## 已知问题与修复记录

| 问题 | 现象 | 修法 |
|---|---|---|
| `skillBonus` 拿不到 perLevel | 契约签名不含 `data`，运行时 data 未就绪 | 静态 import skills.json 作唯一权威源 |
| turnLogic 硬编码技能数值 | 行军 4 / 谋略 10 / 理财 200 三处各写一份 | 改调 `skillBonus`，数值只留 skills.json 一处 |
| 电脑方 pendingLevels 堆积 | AI 升级后没人加点 | `resolveBattle` 内调 `autoChooseSkill` 自动分配 |
| 面板刷新误删固定元素 | `layer.removeAll(true)` 把遮罩/底板一起销毁了 | 卡片单独放 `cardLayer`，刷新只重建该层 |
