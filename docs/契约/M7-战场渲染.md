# M7 · 战场渲染（Phaser 场景）—— ✅ 已交付

> 交付：`src/scenes/BattleScene.js` 重写 + 新增 `src/scenes/battleView.js`（兵牌）、`src/scenes/battleFx.js`（特效）。
> 依赖：M6 战场逻辑（接口已冻结，见契约 M6）、M9 魔法系统。

## 目标

把 M6 的纯逻辑战斗变成可视化、可操作的战斗画面。战场 **11×9** 格，每格 64px，居中偏上；底部 160px 为操作栏。

> 宽度是 11 不是 15：M6b 实测 15 宽时近战兵（moveRange 4）3 回合都碰不到对手，战斗跑不起来。
> 详见契约 M6「战场尺寸」一节。

## 已实现的交互

1. **回合指示**：当前行动单位有**金色描边闪烁**（alpha 1↔0.25 循环，520ms）。
2. **选中与移动**：点我方当前单位 → `movableCells` 高亮青绿格；点击移动走**平移动画**（220ms Cubic.easeOut）。
3. **攻击**：`attackableTargets` 高亮目标（射程内**红环**/超射程**橙环**，橙环提示伤害减半）；
   点击执行 `attackStack`，播**前冲 + 受击抖动 + 伤害飘字**。
4. **兵牌**：单位名首字 + 存活数量；血条（存活/开战）；buff 徽章；特性徽章；射程值。
5. **施法**：✅ M9 已接入（`spellPanel.js` + `[施法]` 按钮 + 选目标模式 + 紫环高亮）。
6. **防御/等待**：`[防御]` / `[待命]` 按钮。
7. **战报**：右下角独立面板，标题带条数，**只渲染可视 7 行**并自动跟到底，滚轮可上翻看历史。
8. **结束**：`battle:end` → `resolveBattle` → 结算面板（胜负/兵力/经验/被俘/占城），点[确定]回地图。
9. **AI 回合**：守方为电脑时自动行动，每步间隔 450ms，期间显示**「电脑方思考中…」**呼吸提示。

## 分层结构

```
BattleScene
├── gridLayer   战场网格（静态，只画一次）
├── markLayer   高亮层：射程覆盖 / 可移动格 / 攻击目标环 / 施法目标环
├── unitLayer   兵牌层（**持久化**）
├── fxLayer     飘字与特效（临时对象，播完自毁）
├── hudLayer    顶栏 + 操作栏 + 结算面板
└── logLayer    战报滚动区（独立于 hudLayer）
```

### 为什么兵牌必须持久化

M7 的动画是对 Phaser 显示对象跑 tween。若每次 `refresh()` 都 `removeAll(true)` 重建兵牌，
tween 的目标对象会在动画播到一半时被销毁 —— 表现为「单位瞬移」「动画不播」。

所以设计成：

- 每个 stack 对应一个 `UnitView`（容器 + 子对象），**只建一次**；
- 数据变了 → 只改文字 / 颜色 / 血条宽度，**不动对象引用**；
- stack 全灭 → 播淡出动画后再销毁。

`BattleScene` 维护 `Map<stackId, UnitView>`（`this.unitViews`），
`refresh()` 时做 diff（新增 / 更新 / 移除）。

> **动画与刷新打架**：`refreshUnitView` 看到 `view.animating === true` 时**不动它的位置**，
> 位置由 tween 控制；动画结束时清标记。这样动画期间的数据刷新不会把单位拽回去。

### 为什么战报区要独立一层

战报需要「滚动到底」且保留滚动位置。若放在 `hudLayer` 里，
每次 `refresh()` 都会重建文本，滚动位置会丢。所以战报放在独立的 `logLayer`。

## 动画清单（`battleFx.js`）

| 函数 | 效果 |
|---|---|
| `floatText` / `floatDamage` | 伤害数字上浮淡出（900ms），击杀数「×N」延迟 120ms 出现 |
| `playMoveTo` | 兵牌平移到目标格（220ms），结束时精确对齐 |
| `playAttackLunge` | 攻击方朝目标前冲（130ms）→ 到位触发命中 → 回位（180ms） |
| `playHitShake` | 受击方左右抖动（55ms × 4），作用于 `body` |
| `playSpellAura` / `playHealAura` | 施法光环扩散（紫 / 绿），群体魔法给全队都画 |
| `playDeathFade` | 阵亡缩小 + 下沉 + 淡出（380ms），完成后销毁视图 |
| `startTurnGlow` / `stopTurnGlow` | 当前行动单位金环闪烁 |

> **前冲与抖动分开动**：`playAttackLunge` 动 `view.root`（整块位移），
> `playHitShake` 动 `view.body`（牌内晃动）。分开后「前冲中又被反击」不会互相打架。

```js

export function cellsInRange(stack) {
  // 切比雪夫距离 ≤ 射程的格子列表（含自身所在格）
}
```

- 口径与 `isOutOfRange` 一致；
- ⚠️ 这是**满伤害范围**。按 M6 远程规则，远程单位其实可以攻击全场任意敌人，
  超出射程只是伤害减半。所以这个格子集用于界面画射程预览，不代表「只有这些格子能被打」；

### 界面层验证踩过的坑（写脚本时要注意）

1. **Phaser tween 要下一帧才推进位置** —— 采样动画状态必须 `await requestAnimationFrame()`，
   否则量到的还是起点，会误判成「没有动画」。
2. **受击抖动是在前冲到位瞬间（130ms）才启动的** —— 单帧采样会漏掉，
   要在时间窗内记录**峰值偏移**。
3. **Phaser 3.90 的 `add.circle()` 返回 `Arc`**（`type === 'Arc'`，不是 `'Circle'`），
   断言要兼容两种。
4. **`add.circle()` 默认是白色实心填充** —— 画「环」必须显式传 `fillAlpha = 0`，
   否则白色圆盘会盖在兵牌上（半径比兵牌大 4px，会露出一圈白边）。
5. **`Rectangle.width` 直接赋值不会更新几何** —— 必须用 `setSize(w, h)`。
6. **Phaser `Graphics` 没有 `createGeometryMask`** —— 战报滚动用「行窗口切片」而非 mask 裁剪。
