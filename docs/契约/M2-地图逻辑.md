# M2 · 地图逻辑（纯 JS，禁止 import phaser）

> 交付 `src/logic/mapLogic.js`。依赖：M0 状态结构（先读 `docs/契约/M0-状态结构.md`）。

## 目标

实现大地图的寻路与移动判定。这是纯算法模块，可在 node 中直接测试。

## 必须导出的函数

```js
/**
 * A* 寻路：在地图上找从 from 到 to 的路径
 * @param {object} map  state.map（含 width/height/tiles）
 * @param {{x,y}} from  起点
 * @param {{x,y}} to    终点
 * @param {Array} [blocked] 额外阻挡格（如其他英雄占位）：[{x,y},...]
 * @returns {Array<{x,y}>|null} 路径（含终点、不含起点）；不可达返回 null
 */
export function findPath(map, from, to, blocked = [])

/**
 * 计算一条路径的行动力消耗
 * 平原1点/格，森林2点/格，道路0.5点/格（两格向下取整合计）
 * @param {object} map
 * @param {Array<{x,y}>} path findPath 的返回值
 * @returns {number} 总消耗（整数，道路两段合一）
 */
export function pathCost(map, path)

/**
 * 执行英雄移动：扣行动力、更新位置、触发事件
 * @param {object} state
 * @param {string} heroId
 * @param {{x,y}} to
 * @returns {{ok: boolean, reason?: string}} 失败时 reason 为 'noPath'|'notEnoughMove'
 * 成功时发事件 bus.emit('hero:moved', { heroId, from, to })
 */
export function moveHero(state, heroId, to)

/**
 * 查询英雄当前可达的所有格子（行动力范围内）
 * @param {object} state
 * @param {string} heroId
 * @returns {Array<{x,y,cost}>} 按 cost 升序
 */
export function reachableTiles(state, heroId)

/**
 * 检查目标格上的交互对象（资源/敌方英雄/敌方城镇）
 * @param {object} state
 * @param {{x,y}} pos
 * @returns {{type: string, ...}|null} 见下
 */
export function checkTileInteraction(state, pos)
// 返回：null | {type:'resource', object} | {type:'enemyHero', hero} | {type:'enemyTown', town} | {type:'ownTown', town}
```

## 约束

- 文件顶部 `import bus from '../core/EventBus.js'`，除此之外不得 import 任何渲染相关模块。
- A* 用曼哈顿距离作启发函数；4方向移动（不走斜线）。
- 山地(2)、水域(3)不可走；其他英雄/城镇所在格视为阻挡（终点除外）。
- 所有函数、注释用中文。

## 语义澄清（实现时必须遵守，已在交付版本落实）

1. **返回路径不含起点**：`findPath` 返回从起点的下一格到终点的序列；起点==终点时返回 `[]`。
2. **起点被占据则无法出发**：`blocked` 含起点坐标时 `findPath` 返回 `null`（因此调用方需把调用者自己排除在 blocked 之外）。
3. **终点可以是 occupied 格**：敌方城镇/英雄格允许作为终点（用于进城与遭遇战），但不可作为中转。
4. **道路消耗按连续段合并后向上取整**：连续 10 格道路 = 5 点；10 格平原 = 10 点；10 格森林 = 20 点。
5. **内部用「半点」整数计费**（平原2 森林4 道路1），对外统一返回整数点数。

## checkTileInteraction 的检查顺序（已修正，务必遵守）

顺序为 **城镇 → 敌方英雄 → 资源 → 己方英雄（返回 null）**：

1. 城镇 → `ownTown` / `enemyTown`
2. 该格上的英雄若是**敌方** → `enemyHero`
3. 该格上有资源 → `resource`（**即使己方英雄正踩在资源上也要返回 resource**）
4. 己方英雄自己脚下且无资源 → `null`

> 早期版本把"己方英雄脚下"直接判为 null，导致英雄踩上资源后无法拾取，此坑已修。

## 验收标准（我会用 node 直接跑）

```bash
node --test "src/logic/**/*.test.js"
```
（交付时须附带 `src/logic/mapLogic.test.js`，覆盖下述用例）

1. 成都到许昌有路径（默认地图上道路连通），且路径为连续四方向步进、不经过不可通行地形。
2. 以湖心 {x:14,y:8} 为终点返回 null（水域不可达）。
3. pathCost 计算正确：全道路 10 格 = 5 点；全平原 10 格 = 10 点；全森林 10 格 = 20 点。
4. reachableTiles 返回的每格 cost ≤ 英雄剩余行动力。
5. moveHero 成功后位置更新、行动力按 pathCost 扣减、并发出 `hero:moved` 事件。
6. 行动力不足返回 `notEnoughMove`，位置不变；无路返回 `noPath`。
7. occupied 格不可穿越，但可作为终点。
