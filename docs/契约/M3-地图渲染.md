# M3 · 地图渲染（Phaser 场景）

> 交付：重写 `src/scenes/MapScene.js`。依赖：M0 骨架（现有 MapScene 是占位版）、M2 地图逻辑。

## 目标

把占位版大地图升级为可玩版本。现有的地形绘制、状态栏可以保留改进，重点补交互。

## 必须实现的功能

1. **选中英雄**：点击己方英雄选中（金色描边高亮）；再点目标格移动。
2. **可达范围显示**：选中英雄后，调用 `reachableTiles` 把可达格画成半透明绿色遮罩。
3. **路径预览**：鼠标悬停在可达格上时，画出 `findPath` 返回的路径（虚线或圆点）。
4. **沿路径移动动画**：英雄沿路径逐格 tween 移动（每格 100ms），移动期间锁定输入。
5. **交互触发**：移动完成后调用 `checkTileInteraction`：
   - `resource` → 资源入玩家账，从 map.objects 移除该对象，发 `resource:changed`；
   - `ownTown` → `this.scene.start('TownScene', { townId })`；
   - `enemyHero` / `enemyTown` → `this.scene.start('BattleScene', { attackerId, defenderId/townId })`。
6. **资源点绘制**：map.objects 里的资源画成小图标（色块+首字，如"金"），被捡走后消失。
7. **结束回合**：调用 M4 的 `endTurn(state)`（若 M4 未交付则保留现有简易逻辑）。

## 契约接口

- 状态：`this.registry.get('state')`；数据表：`this.registry.get('data')`。
- 逻辑函数全部来自 `src/logic/mapLogic.js`，**本场景禁止自己写寻路**。
- 格子尺寸 40px、偏移 (8, 48)，与 M0 保持一致；画布 1280×800。

## 约束

- 单文件交付，中文注释。
- 移动动画用 Phaser tween 链，不用物理引擎。
- 电脑英雄（playerId=1）不可被选中。

## 附：额外导出（M3 交付时补进 mapLogic.js）

| 导出 | 说明 |
|---|---|
| `pickUpResource(state, heroId, pos)` | 资源拾取属规则，放逻辑层：资源入玩家账、从 `state.map.objects` 移除、发 `resource:changed` 与 `resource:picked`。返回 `{ok, resource, amount}`，失败 `{ok:false, reason:'noResource'}` |

## 实现要点（已在交付版本落实）

1. **显示位置与逻辑位置解耦**：动画期间用 `displayPos` 渲染，逻辑位置由 `moveHero` 已改；动画结束再同步，避免英雄"瞬移"到终点再倒着走。
2. **英雄精灵缓存**：`heroSprites`/`heroCircles` 按 heroId 缓存，tween 直接作用于精灵容器，避免每帧重建。
3. **移动期间锁定输入**：`this.moving` 为真时忽略点击。
4. **路径预览**：悬停在可达格时用 `findPath` 画白色圆点；离开即清空。
5. **交互触发时机**：动画结束后才调用 `checkTileInteraction`，避免边走边触发。
6. **资源图标**：按资源类型着色（金黄/木绿/矿灰蓝等）并画首字，拾取后从 `state.map.objects` 移除即自动消失。

## 验收标准

1. 选中刘备后可达格亮绿色，悬停有路径预览。
2. 点击可达格，刘备逐格走过去，行动力按 M2 的 pathCost 扣减。
3. 走到资源格，顶部状态栏金币增加，资源图标消失。
4. 走到成都，切入 TownScene。
5. 浏览器控制台无报错。
