# 出祁山（OutOfQishan）

Phaser 3 复刻英雄无敌4（双阵营简化版）：**蜀汉（生命阵营）vs 曹魏（守序阵营）**，纯 2D 像素美术。

## 运行

```bash
npm install
npm run dev      # http://localhost:5173
npm run check    # 校验数据表（合法性与数值平衡）
npm test         # 逻辑层单测（node --test，253 项）
```

### 浏览器端验证（无头 Chrome，跑真实 Phaser 运行时）

```bash
npm run verify   # 依次跑 m9b → m9c → m7 → m9 → m10 → m11 → m12 → m13 → m14 → map（必须串行，会抢端口）
```

### 美术资源

```bash
npm run art         # 重生成全部像素资源（阵营底座 + AI 图集处理流水线）
npm run shot:m14    # 出两张验收截图（地图 / 战场）
```

资源在 `public/assets/pixel/`（84 张 / 356 KB），由 `src/core/pixelArt.assets.js` 统一登记。
详见 [M14 像素美术契约](docs/契约/M14-像素美术.md)。

## 架构

```
src/
├── main.js            # Phaser 入口
├── core/              # 框架层（M0，已完成）
│   ├── EventBus.js    # 全局事件总线（逻辑↔渲染唯一通信方式）
│   ├── GameState.js   # 单一纯数据状态（可 JSON 序列化 = 可存档）
│   ├── DataLoader.js  # 数据表加载器
│   ├── pixelArt.assets.js # 像素资源清单（M14，纯数据，唯一真相来源，禁止 import phaser）
│   └── pixelArt.js    # 像素资源运行期加载与绘制（M14，含 Graphics 降级回退）
├── logic/             # 逻辑层：纯 JS，禁止 import phaser，可 node 直接测试
│   ├── setup.js       # 开局布置（M0 内置）
│   ├── mapLogic.js    # 寻路/移动/可达范围/格子交互（M2）
│   ├── turnLogic.js   # 回合推进/资源结算/产量刷新/胜负判定（M4）
│   ├── townLogic.js   # 建筑列表/建造/招募/招武将（M5 + M6c 补将）
│   ├── battleLogic.js # 战场：布阵/出手排序/回合推进/伤害/移动攻击/战果结算/射程覆盖（M6a+b+c + M7 cellsInRange）
│   ├── stackOps.js    # 战场底层原子操作：伤害/buff 修正/出手队列（M9，battleLogic↔magicLogic 共用）
│   ├── skillLogic.js  # 经验曲线、经验结算、技能加点三件套（M6c + M8）
│   ├── magicLogic.js  # 魔法系统：施法/buff 生命周期/法力/魔法学习（M9）
│   ├── battleAI.js    # 战斗 AI（M10 完整策略：选靶评分/走位评估/集火 + 规划层与执行层分离）；电脑施法策略（M9）
│   ├── mapAI.js       # 地图 AI（M11：规划层/执行层分离 + 影子状态仿真；电脑回合逐格播放、城务、攻城、战斗中断续跑）
│   └── saveLogic.js   # 存档系统（M12：3 手动位 + 1 自动位 / 版本校验 / 损坏检测 / 深拷贝读档）
├── scenes/            # 渲染层：Phaser 薄壳，只画不算
│   ├── BootScene.js   # 启动：加载数据→建状态→进地图（M12 支持 ?slot=N 深链读档）
│   ├── MapScene.js    # 大地图（M0 占位 → M3 完善 → M11 接入电脑回合驱动 → M12 存档入口与自动存档）
│   ├── TownScene.js   # 城镇：建筑列表 + 招募面板（M5）
│   ├── BattleScene.js # 战场主场景（M7 正式界面：分层渲染/动画/战报/结算）
│   ├── battleView.js  # 兵牌视图（M7，持久化视图：血条/徽章/描边）
│   ├── battleFx.js    # 战场特效（M7，飘字/前冲/抖动/光环/阵亡淡出）
│   ├── DemoScene.js  # 组件库演示（M13，?demo=1 直达，展示 6 个组件）
│   └── ui/
│       ├── components.js # 通用 UI 组件库（M13：按钮/面板/兵牌/toast/确认弹窗/计数器 + 统一配色）
│       ├── skillPanel.js # 技能加点弹层（M8，MapScene/TownScene/BattleScene 共用）
│       ├── spellPanel.js # 施法弹层（M9，列出魔法/法力不足置灰/群体单体标记）
│       └── savePanel.js  # 存档弹层（M12，4 档位：存档/读取/删除 + 摘要时间）
└── data/              # 数据表 JSON（M0 占位 → M1 补全）

docs/
├── 契约/              # M0~M14 模块契约（小模型实现依据）
└── 小模型任务模板.md   # 投喂混元4flash 的 prompt 模板
```

> **存档使用**：地图右上角 `[存档]` 按钮打开存档面板（存档位 1~3 手动存，自动位每天自动写）。
> 刷新页面后可用 `?slot=0`（或 `?slot=auto`）直接回到那一局。
>
> **组件库演示**：访问 `?demo=1` 可打开 UI 组件演示页，直观查看按钮/面板/兵牌/toast/确认弹窗/计数器。

## 分工方式

小模型（混元4flash 等）按 `docs/小模型任务模板.md` 逐模块实现；每个模块交付后按契约里的验收标准检查，不过关把报错原文丢回去修。
